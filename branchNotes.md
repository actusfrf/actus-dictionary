This branch WB_jan2026V01 includes xlsx provided by W Brammertz as of 26th Jan 2026

It includes an updated applicability matrix and some other corrections saved as actus-dictionary_WB_jan2026v01.xlsx.

The current previous stored ( not corrected) dictionary.xlsx is also saved in ths branch as file actus-dictionary.xlsx to facilitate comparison of the current with the proposed "corrected and improved" version from Willi B.

The preferred standards approach is to use these .xlsx files for readbility only.
The ACTUS standard is defined by the content of the machine readable JSON files 
 * actus-dictionary-applicability.json
 * actus-dictionary-contract-reference.json
 * actus-dictionary-event.json
 * actus-dictionary-states.json
 * actus-dictionary-taxonomy.json
 * actus-dictionary-terms.json
 * actus-dictionary.json

There is currently an R script in scripts to convert from .xlsx to .json BUT no
script to convert from .json to .xlsx. This should be fixed ( and raised as an issue on actus-dictionary.
